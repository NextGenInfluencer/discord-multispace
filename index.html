MultiSpace Settings

Performance, privacy, audio, and power-user preferences.

Background Memory Saver Automatically throttles background timers and suspends GIF/CSS animations on accounts idle for >15 minutes (unless inside an active voice call) while keeping incoming DM & call notifications audible. Wakes instantly when clicked.
Launch on Windows Startup Automatically launch Discord MultiSpace minimized in the system tray when your computer starts.
Enable Global OS Shortcuts Register OS-wide hotkeys (Ctrl+Alt+M Mute All, Ctrl+Alt+D Deafen All, Ctrl+Shift+H Boss Key) when unfocused. Disabled by default so AltGr international keys and IDE shortcuts are never hijacked.
Show Quick Reload Button Display the dedicated 1-click reload icon in the sidebar footer. When turned off, you can still right-click the Settings gear for reload options or press F5 / Ctrl+Shift+R.
